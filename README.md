## <a name="introduction">🤖 Introduction</a>

Welcome to the personal portfolio of **Dawn Cobham**, a passionate Frontend Developer based in Nigeria. This project is a showcase of my work, skills, and professional journey, built with a focus on modern design principles, interactivity, and performance.

The portfolio is engineered to provide a seamless user experience, featuring dynamic animations, 3D elements, and a responsive layout that adapts to all devices.

## <a name="tech-stack">⚙️ Tech Stack</a>

- **Framework:** [Next.js 14](https://nextjs.org/) (App Directory)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/), [GSAP](https://gsap.com/)
- **UI Components:** [Aceternity UI](https://ui.aceternity.com/)
- **3D Graphics:** [Three.js](https://threejs.org/) / [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
- **Deployment:** [Vercel](https://vercel.com/)

## <a name="features">✨ Key Features</a>

### 🎨 Premium UI/UX

- **Dynamic Hero Section**: Featuring spotlight effects and text generation animations to grab attention immediately.
- **Bento Grid Layout**: A modern, grid-based layout for presenting skills and personal highlights.
- **Glassmorphism & Gradients**: Extensive use of modern CSS techniques for a sleek, high-end aesthetic.

### 📱 Responsive & Interactive

- **Project Showcase**:
  - **Desktop**: A custom `ProjectScroll` component that horizontally scrolls through projects for an immersive experience.
  - **Mobile**: A stacked, touch-friendly layout ensuring content is accessible visuals on smaller screens.
- **Custom Contact Modal**: A built-in, animated modal form allowing visitors to send messages directly without leaving the page.
- **Micro-interactions**: Hover effects, magnetic buttons, and smooth transitions powered by Framer Motion.

### 💼 Professional Content

- **Comprehensive Experience Timeline**: Detailed work history including roles at Zeroup Academy and Guru Innovation Hub.
- **Testimonials Section**: Infinite scrolling cards capable of displaying client feedback.
- **Direct CV Download**: Easily accessible resume download for recruiters.

## <a name="getting-started">🚀 Getting Started</a>

To run this project locally on your machine, follow these steps:

### Prerequisites

Ensure you have the following installed:

- [Node.js](https://nodejs.org/en) (v18+)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/thatdevelopergirlcobham/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Run the development server**

   ```bash
   npm run dev
   ```

4. **View the application**
   Open [http://localhost:3000](http://localhost:3000) in your browser.
